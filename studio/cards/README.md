# תמונות דמויות לקלפי מלחמה (נסיך/מלכה/מלך/ג'וקר)

כל קובץ כאן הוא **הדמות בלבד** — בלי פינות האות/הצורה ובלי מסגרת הקלף המקורית — כדי שתיכנס
למסגרת של הסטודיו, באותו סגנון כמו שאר הקלפים. רונדרו מ-SVG ל-JPEG (איכות 88); הציור עצמו לא שונה.
ג'וקר קיים רק ב-`fr/` — שאר הסטים משתמשים בו.
