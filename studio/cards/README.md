https://github.com/htdebeer/SVG-cards · npm `svg-cards` · רישיון **LGPL-2.1** (ראו `LICENSE`).

הקבצים כאן הם רינדור של כרטיסי הדמויות מתוך `svg-cards.svg` ל-JPEG (פי 4 מהמידה המקורית,

לא שונה דבר בציורים עצמם. מקור ה-SVG המלא זמין בקישור למעלה, כנדרש ברישיון.
