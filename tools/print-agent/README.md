# סוכן ההדפסה של עיצובישי (S-209)

שרשרת ההדפסה: **מאשרים הזמנה בסטודיו → היא נכנסת לתור → המחשב שליד מדפסת הסובלימציה מוריד את ה-PDF ומדפיס לבד.**

| חלק | איפה |
|---|---|
| התור | טבלאות `print_jobs`, `print_agents` (`supabase/sql/2026-11-27_print_queue.sql`), RLS למנהל |
| השרת | Edge Function `print-queue` (`verify_jwt=false`, הסוכן מזדהה בקוד אקראי — בטבלה רק sha256) |
| המסך | סטודיו → אדמין → "🖨️ שרשרת הדפסה" + בכל הזמנה "🖨️ לאשר ולהדפיס" |
| המחשב | `install.ps1` (פעם אחת) → `print-agent.ps1` רץ ברקע כמשימה מתוזמנת בכניסה ל-Windows |

## התקנה
1. **מדפסת קבועה לסובלימציה ב-Windows:** הגדרות המדפסת של ה-Epson (גודל נייר/גליל, סוג חומר ופרופיל) נשמרות כברירת מחדל *של המדפסת הזו*. ההדפסה היא "Printer Manages Colors" — הדרייבר מנהל את הצבעים לפי פרופיל החומר. הקובץ כבר במראה (מהסטודיו) — לא להפעיל מראה גם בדרייבר.
2. סטודיו → "➕ חיבור מחשב הדפסה" → מעתיקים את הפקודה ל-Win+R, ואת הקוד כשמבקשים.
3. ההתקנה: שומרת את הקוד ב-`%LOCALAPPDATA%\Itzuvishi\print-agent.json`, מתקינה SumatraPDF (winget) ורושמת משימה מתוזמנת `Itzuvishi Print Agent`.
4. בסטודיו: רענון → 🟢 מחובר → בוחרים את המדפסת.

## בדיקה ואז הדפסה אמיתית
- ברירת המחדל **"📁 רק להוריד"** — הקבצים יורדים ל-`C:\Itzuvishi\print\<תאריך>\` ולא מודפס כלום.
- מדפיסים ידנית קובץ אחד מהתיקייה ובודקים צבע וגודל. רק אז — **"🖨️ להדפיס באמת"**.
- ההדפסה: `SumatraPDF -print-to "<מדפסת>" -print-settings "noscale,Nx" -silent` — גודל אמיתי, N עותקים.

## שבת
השרת לא נותן עבודות מ-40 דק׳ לפני השקיעה ביום שישי עד 40 דק׳ אחרי השקיעה במוצאי שבת (שקיעה מחושבת לבקעת הירדן). חגים — עדיין לא.

## תקלות
- יומן: `%LOCALAPPDATA%\Itzuvishi\print-agent.log`
- עבודה שנכשלה מופיעה בתור עם השגיאה → "🔁 שוב". עבודה שנלקחה ולא דווחה תוך 15 דק׳ חוזרת לתור (עד 5 ניסיונות).
- ביטול מחשב: "🗑 מחיקה" בסטודיו — הקוד שלו מפסיק לעבוד מיד.
